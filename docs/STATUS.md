# 青云开发状态

当前版本：`0.1.0-alpha.10`
产品基线：`qingyun_page_design_v4.3.html`（文件名标为 v4.3，HTML 内部 title 仍标 v4.2；实现按该文件实际页面结构执行）。

## 已实现

- Alpha.10：思想伙伴接入 DSH 原生会话的按书籍关联流程。每本书保存独立的 DSH session ID；首次创建本书会话时调用工作台官方 `service.newSession()`，再次打开时调用 `service.open(entry.id, sessionId)` 恢复；通过 `sessionBindings` 校验会话确属青云，避免复用普通会话或其他工作台会话。书籍卡片、首页和思想伙伴入口均可打开对应书籍会话；移除书籍不会擅自删除 DSH 会话。

- Alpha.9：增加 EPUB 原生 ZIP/OPF/spine 解析，按阅读顺序提取 XHTML 正文并转换为可阅读章节文本；解析失败时显示原因，不把未解析文件伪装成正文已导入。PDF 仍待接入。

- Alpha.8：阅读器新增“写下本章思考”，保存为用户确认的“我的观点”手动笔记，自动关联书籍 ID、章节索引和来源；知识库中的章节思考同样可返回原文对应章节。

- Alpha.7：知识库新增书签 / 摘录 / 手动笔记类型筛选和按书籍筛选；章节书签补齐书籍 ID 与 kind；书签、摘录可返回原书对应章节；原书正文缺失或书籍已删除时给出明确提示；手动笔记保存关联书籍 ID（若有）。

- Alpha.6：阅读器支持选中正文并保存为原文摘录，记录书名、章节、书籍 ID 和创建时间；从搜索结果定位时同步保存阅读位置与进度。
- Alpha.5：每本书记忆上次阅读章节；阅读器可将当前章节保存为书本知识书签，并记录书名与章节来源。
- Alpha.4 修复思想伙伴讨论提示的正文节选换行，避免提示内容出现字面量 `\\n`。

- 五个主页面：首页、我的书架、AI 阅读总结、思想伙伴、个人知识库。
- 书架书籍添加、删除、阅读进度记录；TXT/MD/EPUB 正文读取（EPUB 使用浏览器原生解压流与 XML/HTML 解析）。
- TXT/MD 阅读器：自动识别 Markdown 标题及常见中英文书章节标题；没有标题时按 6,000 字符分段；支持全文关键词检索并定位到对应分段；记忆每本书上次阅读章节，并可保存章节书签、选中文本原文摘录到知识库；搜索定位同步更新阅读位置与进度。
- 三档阅读总结提问模板；没有正文时禁止复制总结提示，避免把书名当作读过全文。
- 思想伙伴的理解 / 讨论 / 挑战模式；通过 DSH 工作台服务创建青云归属的原生会话，并显示宿主传入的原生 conversation 节点。
- 知识库分类、记录类型与书籍筛选；书签 / 摘录 / 章节思考来源定位；手动确认保存、编辑、删除。
- JSON 备份导出与导入；导入会替换本地数据并要求确认。
- 空数据不展示虚构书籍、假统计、假 AI 回复或演示图谱。

## 开发约束

- 客户端通过 DSH 官方要求的 `window.__ModuleLoader__.load()` 注册；工作台通过 `desktopWorkbenches.register()` 注册。
- 原生会话由 DSH 管理；青云不另造假聊天 UI。
- 不猜测或伪造图谱 API。未获得可验证的数据接口前，知识图谱显示明确空状态。
- 用户数据保存在客户端本地存储；导出的 JSON 备份可能包含导入正文和个人观点。
