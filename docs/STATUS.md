# 青云开发状态

当前版本：`0.1.0-alpha.3`
产品基线：`qingyun_page_design_v4.3.html`（文件名标为 v4.3，HTML 内部 title 仍标 v4.2；实现按该文件实际页面结构执行）。

## 已实现

- 五个主页面：首页、我的书架、AI 阅读总结、思想伙伴、个人知识库。
- 书架书籍添加、删除、阅读进度记录；TXT/MD 正文读取。\n- TXT/MD 阅读器：自动识别 Markdown 标题及常见中英文书章节标题；没有标题时按 6,000 字符分段；支持全文关键词检索并定位到对应分段。
- 三档阅读总结提问模板；没有正文时禁止复制总结提示，避免把书名当作读过全文。
- 思想伙伴的理解 / 讨论 / 挑战模式；通过 DSH 工作台服务创建青云归属的原生会话，并显示宿主传入的原生 conversation 节点。
- 知识库分类、手动确认保存、编辑、删除。
- JSON 备份导出与导入；导入会替换本地数据并要求确认。
- 空数据不展示虚构书籍、假统计、假 AI 回复或演示图谱。

## 待接入 / 待验收

- PDF/EPUB 正文解析、目录与页码定位。
- DSH 模型自动总结、候选观点抽取与用户确认流程。
- DSH 知识图谱数据源、节点/边映射、图谱选择与跳转。
- 目标 Windows DSH Desktop 0.2.x 实机安装、工作台注册、会话创建和 UI 验收。

## 验证记录

- `package.json` 可解析；包名、Cordis patch 的插件名和客户端模块加载 ID 一致。
- DSH 客户端声明 `platform: web`，并依赖 `dsh-desktop-workbenches` 的先行加载。
- 客户端与 Host 入口通过静态 JavaScript 语法检查。
- 以上是静态检查，不等同于目标 Desktop 的运行验收。

## 开发约束

- 客户端通过 DSH 官方要求的 `window.__ModuleLoader__.load()` 注册；工作台通过 `desktopWorkbenches.register()` 注册。
- 原生会话由 DSH 管理；青云不另造假聊天 UI。
- 不猜测或伪造图谱 API。未获得可验证的数据接口前，知识图谱显示明确空状态。
- 用户数据保存在客户端本地存储；导出的 JSON 备份可能包含导入正文和个人观点。
