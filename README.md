# 青云 QINGYUN

青云是一个面向 DSH Desktop 的私人阅读工作台，按页面设计 v4.3 的信息结构实现：首页、我的书架、AI 阅读总结、思想伙伴、个人知识库。

## 当前 alpha 范围

- 书架：添加书籍、导入 TXT/MD/PDF/EPUB 文件条目、记录阅读进度。
- 阅读总结：按快速了解、理解全书、深入重点生成提问模板，交给 DSH 原生会话处理。
- 思想伙伴：嵌入 DSH Desktop 提供的原生会话节点；不自建模拟聊天。
- 个人知识库：保存用户手动确认的知识和观点。
- 本地数据：当前保存在浏览器本地存储；卸载插件不会主动清除这些数据。

## 当前限制（明确标注）

- TXT/MD 可读取正文；PDF/EPUB 目前只登记文件信息，尚未解析正文。
- 阅读总结与知识图谱尚未自动调用 DSH 模型生成；当前通过提问模板连接原生 DSH 会话。
- 知识图谱尚未实现，页面不会用演示数字或假关系冒充真实数据。
- 本仓库代码尚未在用户的 DSH Desktop 0.2.x 环境完成安装与运行验收。

## 安装与开发

本包遵循 DSH Desktop 工作台开发规范。客户端入口为已提交的单文件 lib/client.js。

官方规范：
- https://dshdesktop.com/workbench/docs/development/
- https://dshdesktop.com/workbench/docs/quickstart/

## 数据与隐私

青云当前仅将书籍元数据、TXT/MD 正文和手动记录保存在当前 DSH 客户端的本地浏览器存储中。请勿导入不希望存放在本机浏览器配置中的敏感材料。卸载工作台不会主动删除本地存储。
