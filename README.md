# 青云 QINGYUN

青云是面向 DSH Desktop 的私人阅读工作台，按页面设计 v4.3 的五个入口实现：首页、我的书架、AI 阅读总结、思想伙伴、个人知识库。

## 当前版本：0.1.0-alpha.16

- **首页与书架**：真实本地统计、添加书籍、阅读进度、TXT/MD/EPUB 正文导入；支持 TXT/MD 正文分章阅读、章节目录、关键词检索与定位；记忆每本书上次阅读章节，并可将当前章节保存为书签、选中正文保存为带书名和章节来源的原文摘录，统一进入个人知识库；知识库可按书籍、记录类型和知识分类筛选，书签、摘录和章节思考可返回对应原文章节；阅读器可直接记录关联当前章节的个人思考；EPUB 可按阅读顺序提取章节正文；PDF 目前只登记文件信息。
- **AI 阅读总结**：5 分钟快速了解、15 分钟理解全书、深入重点三档分析；点击“发送到 DSH 生成总结”后，青云将全文分块交给本书专属 DSH 会话，由 DSH AI 生成回复（结果显示在原生会话中，尚未实现青云内独立总结报告卡片）。
- **思想伙伴**：理解、讨论、挑战三种交流模式；讨论提示中的正文内容使用真实换行，便于在 DSH 原生会话中阅读；每本书独立关联一条 DSH 原生会话：首次创建并绑定，再次打开恢复原会话；用户明确触发后，将当前已导入的完整正文交给 DSH 原生会话；不再由青云设置 48,000 / 18,000 字符截断上限。DSH 或模型上下文容量不足时，必须如实提示，不能宣称完整处理。
- **个人知识库**：书本知识、我的观点、思想变化分类；支持手动确认保存、编辑、删除、分类筛选；区分章节书签、原文摘录和手动笔记，并可按书籍筛选；阅读器支持写下与当前章节关联的阅读思考。
- **数据备份**：导出 / 导入 JSON 备份；导入会替换当前本地数据，操作前会二次确认。
- **真实数据原则**：没有真实数据时显示空状态，不使用演示书籍、假统计、虚构 AI 回复或虚构知识图谱。

## 尚未完成

- PDF 正文解析与页码定位尚未接入。
- 书籍正文仍保存在青云本地数据中；用户点击“发送本书资料到 DSH”后，青云通过 DSH 原生会话 prompt 接口发送当前书籍资料，当前将完整正文切成 12,000 字符文本块，作为同一条原生 session.prompt 请求的多个 content block 发送；分块没有总量上限。大文件附件上传、跨请求分段索引仍待实现。单次请求或模型上下文可能存在宿主容量限制。AI 自动总结、自动观点提取、跨书知识关系和图谱视图仍待接入可验证的 DSH 数据接口。
- 真实安装和运行验收尚未在用户的 Windows DSH Desktop 0.2.x 环境完成。

## 安装与开发

仓库：https://github.com/zhihaoyisheng-design/qingyun-dsh-plugin

DSH Desktop → 插件 → 添加插件，粘贴仓库地址。当前为早期 Alpha，尚未完成目标设备验收，不建议作为唯一知识数据存储。

客户端入口是 DSH Desktop 工作台规范要求的单文件模块加载入口；工作台注册使用 `desktopWorkbenches.register()`，会话由 DSH 原生服务管理。

## 数据与隐私

书籍元数据、TXT/MD 正文和手动记录保存在当前 DSH 客户端浏览器本地存储。导出备份包含导入正文和个人记录；请妥善保管。卸载插件不会主动清除本地数据。
